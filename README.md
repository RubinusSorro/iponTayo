# 💰 iponTayo v1.5

iponTayo is a modern savings tracker web application that helps users manage their financial goals, track contributions, and stay motivated.

---

## 🚀 Features

- 🔐 Authentication (Email & Google Login)
- 📊 Real-time savings tracking (Firebase Firestore)
- 💸 Deposit system with validation (goal cap, input checks)
- 📈 Analytics dashboard (monthly trends, averages)
- 🌙 Light/Dark theme support
- 👤 Profile management (update info, delete account)
- 📱 Fully responsive (mobile + desktop)
- ⚡ Fast and optimized with Vite + React

---

## 🧠 Tech Stack

- **Frontend:** React + Vite + Tailwind CSS
- **Backend:** Firebase (Auth + Firestore)
- **Charts:** Recharts
- **Icons:** Lucide React
- **State Management:** React Context API

## 🔧 Setup & Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/ipontayo.git
cd ipontayo

2. Install dependencies
npm install

3. Create a .env file in the root
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id

4. Run the development server
npm run dev
```
